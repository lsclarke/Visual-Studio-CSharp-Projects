# Car Rental Management Project
-----------------------------------------------------------------------------------------------------------------
I created this project to demonstrate the process of purchasing a rental car for an extended period of time. 
The project features mutiple functions that allow for manipulating characteristics and features for the vehicle you wish to rent.
The program will also calculate a final total that will be different depending on the extra features of each vehicle. 
If a vehicle has seat warmers and has a built in navigation system the pricing could be expensive.
